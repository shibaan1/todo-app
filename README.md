---

## 🚀 Features

- ✅ Add a task
- ✅ Mark task as complete / undo
- ✅ Delete a task
- ✅ Task counter — "X completed out of Y"
- ✅ Filter tasks — All / Active / Completed
- ✅ Clear All button
- ✅ localStorage — tasks survive page refresh

---

## 🛠️ Built With

- **HTML5** — semantic structure
- **CSS3** — CSS Grid, Flexbox, dark theme
- **Vanilla JavaScript** — DOM manipulation, event delegation, localStorage

---

## 💡 Key Concepts Used

- **Event Delegation** — one listener on `#tasklist` handles all task buttons
- **localStorage + JSON** — tasks persist across page refreshes
- **CSS Grid** — two-column layout (1/3 input, 2/3 tasks)
- **Flexbox** — internal layouts and alignment
- **Error Handling** — empty input validation with trim()
